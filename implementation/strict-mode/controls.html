How to use

Apply settings, then reload affected pages. Turning OFF removes the rule for future document loads; an already sandboxed page needs reloading. Existing site CSP is preserved.

This is the native popup-denial layer, not the complete ad blocker. Same-tab redirects are not filtered. Downloads, modal dialogs and other sandbox-controlled features may be restricted. Not every service-worker/non-network response is covered. No automatic certificate bypass is enabled.

This build does not count all blocked attempts or recover popup handshakes. The controlled test reports whether its own window.open returned a handle.
